# WD4E_CapstoneProject
Culmination of the Web Design for Everyone course on Coursera by Colleen Van Lent. This project will create a website with at least three separate webpages. It will also be using responsive design so that there will be mobile, tablet and large screen views. 

Currently using the same images for all three separate webpages and the theme is North American dog breeds as I re-used code from previous assignments for this site.

The website can be found at: https://dani-eng.github.io/WD4E_CapstoneProject/
